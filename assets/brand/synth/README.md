# SYNTH Brand Assets

This folder is reserved for canonical SYNTH brand assets derived from the
approved concept sheet and governed by:

- [synth_brand_v1.md](/home/gurk/projects/synth-v2/docs/brand/synth_brand_v1.md)

## Canonical Brand Name

`SYNTH`

## Canonical Subtitle

`Cybernetic Zen Master with Market Data`

## Planned Asset Groups

- `master/`
  Master logo treatments for hero and editorial surfaces.
- `accent/`
  Violet-accent variants that preserve the same canonical `S` silhouette.
- `monochrome/`
  Flat one-color assets for print, accessibility, and constrained UI use.
- `favicon/`
  Small-size simplified symbol-only exports.

## Asset Rules

- Keep the interlocked `S` monogram recognizable without glow.
- Do not use the composite concept sheet itself as a favicon.
- Do not place the subtitle into small UI lockups.
- Monochrome assets must remain clearly identifiable as SYNTH.
- Keep public assets plain and product-facing; internal lore belongs in docs,
  not embedded into the logo file naming or exports.

## Suggested Naming

- `synth_master_dark_v1.*`
- `synth_accent_dark_v1.*`
- `synth_monochrome_black_v1.*`
- `synth_monochrome_white_v1.*`
- `synth_favicon_symbol_v1.*`

No generated exports are added by this change. This README establishes the
canonical asset folder contract only.
