## Purpose

Analyze Breath Curve phase-shift bands to determine whether selected offsets cluster around harmonic bands and how narrow those bands can be.

This report tests whether offsets around:

    -10.5, -9, -7, -5, -3, 0, +3, +5, +7, +9, +10.5

act as meaningful discrete phase bands.

## Method

Input is a partial-to-full Breath Curve CSV generated by:

    src/research/backtest_breath_curve_partial_to_full_v1.py

Recommended fine-offset run:

    offsets = -10.5 .. +10.5, step 0.5 day

The analyzer summarizes:

- selected partial offset distribution
- best full offset distribution
- selected offset band fit
- best full offset band fit
- offset_match rate by band
- average partial score
- average full score
- average return to 1.000
- average return to 1.272
- positive rate
- checkpoint-specific buckets
- symbol-specific buckets

## Why this matters

Before testing superoverflow, the phase lens must be calibrated.

If the phase band is too wide, overflow detection becomes vague.
If the phase band is too narrow, valid harmonic drift is missed.
